# Inferred-WB 诊断结果

67 项 pytest 全部通过；80 次正式拟合全部完成。数据生成器和 split 实现未修改，原始真值及拆分通过逐项核对。所有均值/标准差来自同一队列的 5 个模型种子，不是独立队列的置信区间。

## WB 与梯度链

模型可训练参数仅有 raw_WS、raw_HC、raw_HO、raw_HI、phenotype_head.gamma。WB 不是 Parameter，每次 forward 从 CB/IB 与当前字典推断。训练/测试同输入推断最大差值为 0。

仅 Cox loss 的梯度范数：WB=0.057545, HC=0.151068, HI=0.079220, gamma=0.034193。有限差分、标签独立性及同路径测试通过。

## 诊断判断

- 不是单纯 capacity problem：增加到 K=6/8 没有稳定消除冲突，尤其无监督完整模型仍为 80%–100% 冲突。监督 K=6 的 B 恢复改善，说明容量竞争可能有贡献。
- composition 的训练干扰尚不能单独确认：完整模型监督 K=4/6 的 HI-only 冲突本已为 0%，而 HC+HI 冲突为 40%/20%，说明组成还会影响匹配指标；移除组成后 B 的 HI/WS 恢复并没有系统提高。
- CCC-only 监督组虽然 collision=0%，HI A/B cosine 和 WS correlation 仍不高，learned HI pair cosine 约 0.66，而真实 A/B HI cosine 约 0.025。不同索引并不等于真实生态位已被恢复。
- 主要证据指向 CCC factorization 的分离/优化问题，同时伴随容量竞争和组成匹配影响；有限优化和近似 inner inference 不能证明严格的数学不可辨识性。
- 不支持 activity confounding 是主要原因：A/B 真值活性相关较弱，B 与 eta 及生存 proxy 也接近零。

没有据这些结果添加新的模型、正则项或调节生成器。
