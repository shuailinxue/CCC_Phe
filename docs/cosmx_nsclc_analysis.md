数据来自He等人2022年肺癌CosMx研究，经公开注释容器提供：
https://doi.org/10.6084/m9.figshare.25976224.v2 。完整文件2,755,776,882字节；MD5为71a84bdcf3cc625431aded47bad9a109。只读取原始counts、样本/供者/FoV/细胞ID、作者细胞类型及空间坐标；不读取容器中的CellCharter、scVI或已知niche信息。原始细胞数765,771；counts≥50、有效注释及坐标后保留702,199细胞、960基因、8切片、5供者。坐标与原始Lung6像素元数据核对后乘0.18转换为微米。

参考切片为LUAD-5 R1/R2、LUAD-9 R1/R2、LUAD-12、LUAD-13，共526,785细胞。LUAD-5 R3为重复切片查询，LUSC-6为新供者查询，共175,414细胞。查询不参与LR筛选、均值/尺度标定、基因标准化、GNN训练、几何标定或checkpoint选择。所有30成员物理图严格在原切片内建立。

模型保持当前有向细胞–边联合编码器、共享h96、两个直接预测MLP和近/中/远距离保持loss。最多30轮，至少20轮；参考训练总loss相对改善不足0.2%连续7轮后早停，学习率可降低，最终恢复参考训练总loss最低的权重。这里没有独立验证集，不能把最低训练loss称为最优泛化结果。

参考KMeans固定K12，只拟合参考h；查询以冻结编码器和最近参考中心赋值。亲和度为相对中心距离分数，不是生物学概率。全部切片冻结推理后另做K16联合探索分群；这一步包含查询h，是下游探索，不是参考训练或独立映射评估。所有KMeans使用与训练相同的固定全局h校准，10次初始化，不解码宽CCC作聚类、不逐细胞单位化。联合与参考标签的编号对齐仅为参考细胞上的最大重叠排列，不改变任何分区。

图形借鉴NicheCompass Fig.5的证据顺序：完整细胞图谱、niche/细胞类型/供者的共同UMAP、全切片niche、冻结查询映射、组成与有向CCC、供者9/12界面和免疫空间结构。UMAP使用所有细胞的聚类h，不将UMAP分离程度当成准确性。图形输出PNG、PDF及保留文字的SVG，散点栅格化；每张图有来源和选择条件JSON。

局部区域根据原始细胞类型和空间几何选取，不根据niche标签挑选。免疫交错/外围富集是描述性几何代理，不声称病理确诊浸润或排斥。“组成相近、通讯不同”在同切片不重叠窗口中，要求组成总变差≤0.10、单类型差≤0.06，再探索原始CCC差异；这一案例是训练后探索，不是独立验证，未满足条件就不画。CCC富集要求观测支持，不将预测富集或邻域细胞当成独立重复做显著性宣称。
