# V1006

Deep prototype directed-CCC analysis for Xenium Prime 5K Breast. The model first learns a nonnegative 32-dimensional nonlinear autoencoder representation. A fixed train-derived PCA whitening transform removes the shared latent direction before eight cosine prototypes are learned with a prototype-only warm-up, assignment consistency and anti-collapse constraints. Niche interpretation uses soft-weighted profiles of the observed CCC vectors. Composition, spatial graphs, Leiden, bulk outcomes and cross-dataset information are excluded from training.

Open `XeniumPrime5K_Breast_V1006_niche_walkthrough.ipynb` and use **Run All**. Existing valid V1003 CCC caches and complete V1006 results are reused automatically.
